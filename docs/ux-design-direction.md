## 三、產品頁應包含內容

### 3-1 產品列表頁（/products/score-cut/）

```
區塊順序：
1. Breadcrumb（麵包屑）：Home > Products > Score Cut
2. 系列 Hero：系列名稱 + 一句話說明 + 適用材料 Tag
3. 篩選列：依壓力 / 最小切寬 / 導桿類型
4. 產品卡 Grid：
   - 產品圖
   - 型號（MT-A110）
   - 2–3 個關鍵規格
   - [View Details] 按鈕
5. 系列比較表：主要型號規格對比
6. 側邊浮動 CTA：「Need Help Choosing? Get a Quote」
```

---

### 3-2 產品詳細頁（/products/score-cut/mt-a110/）

```
區塊順序：
1. Breadcrumb
2. 產品大圖（左）+ 核心資訊（右）
   ├── 型號名稱（大字）
   ├── 系列標籤
   ├── 一句話定位（Under 12mm precision slitting...）
   ├── 關鍵規格快速覽：
   │   精度 ±0.005mm / 最小切寬 12mm / 最大速度 100M/min
   │   氣壓 3~6 kg/cm² / 刀片直徑 Ø76.2mm
   └── [Get a Quote for This Product] 橙色大按鈕
3. 圖片輪播（多角度實拍）
4. Tab 切換內容：
   ├── [Specifications] 完整規格表
   ├── [Applications]   適用材料 + 適用場合
   ├── [Compatible]     配套導桿 / 刀片型號
   └── [Downloads]      PDF 型錄下載（EN / 繁中）
5. 嵌入式詢價表單（側欄或頁面底部）
   ├── 需求類型：更多資訊 / 索取報價 / 訂購
   ├── 姓名、公司、Email、電話、國家
   ├── 材料選擇（下拉）
   └── 切割速度、材料厚度
6. 相關產品推薦（同系列其他型號）
```

## 四、CTA 設計（詢價流程）

### 4-1 三層 CTA 架構

```
第一層：導覽列固定按鈕（每頁都看得到）
─────────────────────────────────────
位置：Header 右側
文字：Get a Quote
顏色：橙色 #E07830，白色文字
行為：點擊跳至 /contact 或開啟側邊表單

第二層：浮動按鈕（全站跟隨）
─────────────────────────────────────
位置：右下角 fixed
文字：Find the Right Solution（參考 Helios）
顏色：橙色
行為：點擊展開材料選型 Modal，或跳至 /contact

第三層：頁面內嵌 CTA（每個重要頁面底部）
─────────────────────────────────────
首頁底部：大型橙色區塊 CTA
產品頁側欄：嵌入式表單
應用頁底部：「Get Recommendation」按鈕
```

### 4-2 詢價表單設計（參考 Double E Group）

```
Step 1 — 需求選擇（3 選 1）：
  ○ More Information    ← 只想了解
  ○ Request a Quote     ← 需要報價
  ○ Order Product       ← 直接訂購

Step 2 — 聯絡資訊：
  姓名*        公司名稱*
  Email*       電話
  國家*        職稱

Step 3 — 需求說明：
  材料類型（下拉）
  切割速度（M/min）
  材料厚度（mm）
  感興趣的產品型號（可選）
  備註

Step 4 — 送出（橙色按鈕）
  [Submit Request  ▶]

送出後：感謝頁，說明 24–48 小時內回覆
```

### 4-3 轉換路徑設計

```
訪客進入首頁
    ↓
Hero 區：看到品牌 → 點 [Explore Products]
    ↓
產品頁：找到感興趣型號 → 看規格
    ↓
產品詳細頁：側欄表單 or 底部 [Get a Quote]
    ↓
填寫表單 → 送出 → 感謝頁
    ↓
業務收到通知 → 24hr 內回覆
```

## 五、手機版 UX 注意事項

### 5-1 導覽列

- 漢堡選單（三橫線圖示），點擊展開全螢幕選單
- 漢堡選單展開時，底部固定顯示「Get a Quote」橙色按鈕
- Logo 置中或左對齊，高度壓縮至 56px
- 選單展開時背景模糊 blur 效果

### 5-2 Hero 區塊

- 產品圖縮小，文字保持可讀性（最小 18px）
- CTA 按鈕寬度 100%，高度 52px（手指易點擊）
- 精度數字保留，調整排版為垂直堆疊

### 5-3 產品卡

- 單欄顯示，卡片高度固定
- 圖片 4:3 比例
- 關鍵規格只顯示 2 項（避免資訊過載）

### 5-4 表單

- 每個欄位獨立一行，高度 48px 以上（方便輸入）
- 下拉選單改用原生 select 或 Sheet 彈出式
- Submit 按鈕：全寬 100%，高度 56px，橙色
- 輸入法彈出時畫面不跳位（設定 viewport meta）

### 5-5 浮動 CTA

- 手機版浮動按鈕改為底部全寬固定列
- 文字縮短：「Get a Quote」，不顯示副標
- 在表單頁本身隱藏，避免遮擋

### 5-6 效能

- 首屏圖片使用 WebP 格式 + lazy loading
- 手機版 Hero 圖片使用較小尺寸（srcset）
- 字型僅載入 Latin + Latin-Extended（減少台灣/歐洲用戶等待）

## 六、設計系統規範

### 色彩
```
主色    #1a2b3c    深海藍（導覽、深色區塊）
強調色  #E07830    橙色（所有 CTA、重要標籤）

文字主  #1a1a1a    正文
文字次  #6b7280    說明文字
邊框    #e5e7eb    分隔線
```

### 字型
```
英文標題   DM Sans Bold / Barlow Condensed（工業感）
英文正文   DM Sans Regular / Inter
中文       Noto Sans TC
德文       同英文字型（Latin 字集完整）
```

### 間距系統
```
基礎單位 4px
區塊上下間距：80px（桌面）/ 48px（手機）
卡片內距：24px
按鈕高度：48px（桌面）/ 52px（手機）
```

### 圓角
```
按鈕：4px（工業感，不過圓）
卡片：8px
圖片：4px
Modal：12px
```
