## CTA 設計參考案例

### Intertech Precision 模式（固定導覽列按鈕）
```
位置：導覽列最右端

行為：點擊跳至詢價表單頁

```

```
特點：不需跳頁，看完產品立刻填表
```

## 3 大最佳參考模板建議

### 🥇 第一推薦：Helios Slitting（設計方向）
- **學習重點：** 全黑 Hero + 3D 產品渲染 + 浮動 CTA + 切法說明三位一體
- **適用於 MOTOKNIFE：** Hero 設計、CTA 策略、切法說明架構
- **具體建議：** Hero 用黑底展示高精度刀座 3D 渲染/實拍，右下角放浮動「找適合的刀座」黃色按鈕

### 🥈 第二推薦：Mario Cotta（內容架構）
- **學習重點：** 按材料分類的 9 大行業應用場景
- **適用於 MOTOKNIFE：** 產品應用場景頁面規劃
- **具體建議：** 建立「您的材料」分類頁（鋁箔/銅箔/塑膠薄膜/橡膠/紙…），每類說明對應產品

### 🥉 第三推薦：DIENES（服務生態）
- **學習重點：** 技術培訓 + 到廠診斷 + 試用服務的呈現方式
- **適用於 MOTOKNIFE：** 服務頁面、建立差異化優勢
- **具體建議：** 增加「免費樣品測試」「技術顧問諮詢」服務頁面，降低歐洲客戶遠距採購障礙
